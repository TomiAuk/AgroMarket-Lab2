# Лабораторная работа №2 — DOM, Fetch API и Git/GitHub

## Что реализовано
- `db.json` содержит четыре товара.
- `json-server` предоставляет список по адресу `http://localhost:3001/products`.
- `script.js` загружает товары через `fetch()` и `async/await`.
- Карточки создаются динамически через DOM.
- Кнопка «В корзину» увеличивает счётчик.
- Есть обработка ошибки, если сервер недоступен.

## Запуск
1. Установить Node.js.
2. Открыть терминал в этой папке и выполнить `npm install`.
3. Запустить API: `npm run server` и оставить терминал открытым.
4. Открыть `index.html` через расширение Live Server в VS Code.

Для задания по методичке история репозитория должна включать коммиты первой и второй лабораторной. Если у вас уже есть репозиторий из ЛР1, используйте его вместо создания нового.

## Как объяснить `loadProducts()`
Функция отправляет HTTP-запрос на json-server, проверяет успешность ответа, преобразует ответ в JSON и передаёт массив товаров в `renderProducts()`. `async/await` позволяет записать асинхронный запрос в понятном последовательном виде.
